## What
Add the request methods of `SessionModel` in `Sources/FoundationModelsACPClient/Model/SessionModel+Prompt.swift`. The model sends through an internal protocol `SessionRequestSender` (`prompt`, `cancel`, `setConfigOption`); `ConnectionModel` gives the real sender, and tests give a fake.

- [ ] `public func prompt(_ content: [ContentBlock], meta: Meta? = nil) async throws -> PromptResponse`: before it sends, it appends a local user-message entry (`origin: .local`, `sendState: .pending`, `messageId: nil`).
- [ ] Link with the FoundationModelsACP messageId helper: the `PromptResponse.messageId` or the echoed `user_message` with the same id, whichever comes first, sets the entry's `messageId` and `sendState = .sent`. The entry keeps the same object and the same `id`. The echo must not add a second user-message entry.
- [ ] On failure, set `sendState = .failed` and append a local `error` entry with the JSON-RPC `code`, `message`, `data` (from `RequestError` / `ConnectionError`), then rethrow. `public func appendError(code:message:data:)` for a request that the model did not send.
- [ ] `public func cancel(meta: Meta? = nil) async throws` sends `session/cancel`. `public func setConfigOption(_ request: SetSessionConfigOptionRequest) async throws` sends the request (the agent reports the new values through `config_option_update`). The `meta` lets a caller give the trace parent (acp-client does this).

## Acceptance Criteria
- [ ] Response first, then echo: one user-message entry, linked, same `id` before and after the link.
- [ ] Echo first, then response: one user-message entry, linked.
- [ ] A failed prompt gives `sendState == .failed` and an error entry with the code, message, and data.
- [ ] The pending entry exists before the sender receives the request.

## Tests
- [ ] New `Tests/FoundationModelsACPClientTests/Model/SessionModelPromptTests.swift` with a fake `SessionRequestSender`: the two orders, stable `id`, the failure path, `appendError`, entry-before-send, and that `cancel(meta:)` and `setConfigOption` pass their values to the sender unchanged.
- [ ] `swift test --filter SessionModelPromptTests` passes.
