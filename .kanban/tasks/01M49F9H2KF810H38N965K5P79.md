## What

ACP v2 session setup (https://agentclientprotocol.com/protocol/v2/session-setup) says that to resume a session later, the client must keep the `sessionId`, the original `cwd`, and the `additionalDirectories`:

- On `session/resume`, the request `cwd` MUST match the `cwd` of the session.
- On `session/resume`, the client must send the full intended `additionalDirectories` list again. An omitted or empty list activates no additional roots.
- The client may send `additionalDirectories` only when the agent advertises `session.additionalDirectories` (`SessionAdditionalDirectoriesCapabilities`).

Now `SessionModel` keeps none of these values, so AgentViewKit must keep its own copy.

1. In `Sources/FoundationModelsACPClient/Model/SessionModel.swift`, add:
   - `public internal(set) var cwd: AbsolutePath?`. `nil` means only that no `session/new` or `session/resume` set it (a model that a unit test makes directly). It is optional because 33 test call sites make `SessionModel` directly.
   - `public internal(set) var additionalDirectories: [AbsolutePath] = []`.
2. In `Sources/FoundationModelsACPClient/Model/ConnectionModel+Sessions.swift`:
   - `newSession(_:)`: set `cwd = request.cwd` and `additionalDirectories = request.additionalDirectories ?? []` before `register(_:openedOver:)`.
   - `resumeInTurn(_:)` / `replay(_:into:over:)`: set both values from the request after a successful response, for a new model and for an open model. A failed resume changes neither value.
   - When `request.additionalDirectories` is not empty and `canUseAdditionalDirectories` is `false`, throw `ConnectionModelError.unsupported(method:)` and send nothing.
3. In `Sources/FoundationModelsACPClient/Model/ConnectionModel+Initialize.swift`, add `public var canUseAdditionalDirectories: Bool { agentCapabilities?.session?.additionalDirectories != nil }`.
4. Document on `SessionModel.cwd` that a host resumes with `ResumeSessionRequest(cwd: session.cwd!, sessionId: session.sessionId, additionalDirectories: session.additionalDirectories)`, and that the agent refuses another `cwd`.

## Acceptance Criteria

- [ ] After `newSession(_:)`, `session.cwd == request.cwd` and `session.additionalDirectories` is the request list (or empty).
- [ ] After `resumeSession(_:)`, the model has the `cwd` and the `additionalDirectories` of the request, for a new model and for an open model.
- [ ] A failed resume keeps the earlier values.
- [ ] A request with `additionalDirectories` and no `session.additionalDirectories` capability throws `unsupported` and sends no frame.
- [ ] `canUseAdditionalDirectories` follows the `initialize` answer.
