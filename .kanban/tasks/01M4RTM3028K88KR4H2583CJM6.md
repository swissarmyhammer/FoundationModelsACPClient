## Goal
A SwiftUI `#Preview` and a host app test must be able to make a populated `SessionModel` and `ConnectionModel` with no agent and no connection. Now this needs `@testable import` and the private test fixtures (`Tests/.../SessionModelFixtures.swift`, `FakeSessionRequestSender.swift`).

## Change
- Add a public, `@MainActor` factory API. Example shape (the implementer can change the names to agree with the code):
  - `SessionModel.preview(sessionId:cwd:transcript:availableCommands:configOptions:mcpServers:pendingPermissions:)`
  - `ConnectionModel.preview(state:sessions:openSessions:authState:initializeResponse:)`
- Give a transcript as a list of simple values, for example `.user("text")`, `.agent("text")`, `.thought("text")`, `.toolCall(...)`, `.plan(...)`, `.terminal(...)`, `.error(...)`. The factory folds them through the same engine that the live model uses, so a preview shows the real state.
- Add a public preview request sender that does not use the network. `prompt` appends the user message and gives a fixed answer, or never answers. `cancel` and `setConfigOption` do nothing. Do not add a busy state or a turn state.
- Use `.zero` coalescing cadence and a fixed wall clock, so a preview is the same each time.
- Give some ready samples, for example `SessionModel.previewSample` with a short conversation, one tool call, and one pending permission.
- Change the existing test fixtures to use the new factories where this removes duplicate code. Do not change the behavior of the tests.
- Put the code in `Sources/FoundationModelsACPClient/Preview/`. Do not import SwiftUI in the library.

## Acceptance criteria
- [ ] A file that has only `import FoundationModelsACPClient` (no `@testable`) can make a `SessionModel` with each kind of transcript entry, and a `ConnectionModel` with two open sessions in order.
- [ ] A preview model never opens a process or a socket.
- [ ] `prompt` on a preview model adds a user message entry, and its `sendState` changes as it does in the live model.

## Tests
- Add a test target file that uses only the public API (no `@testable import`), and builds each factory and each sample.
- Run `swift test`. All tests must pass.
