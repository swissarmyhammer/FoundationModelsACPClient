## What

Milestone **N5** of this repository's `cli-plan.md` §10.

Asked for by `FoundationModelsACPAgent`, card `^3jdqyn5`.

`acp-client doctor -- <agent-command>` answers one question about a
foreign agent: is it usable? One `Doctorable` conformance over an agent
command:

| Check | Catches |
|---|---|
| The command exists on `PATH`, or at the given path, and it is executable | A typing mistake, or a binary that was not built |
| The process starts, and it does not exit at once | A missing runtime, or a crash on start |
| It writes valid ndJSON, and nothing else, to stdout | An agent that prints a banner to stdout |
| `initialize` answers inside the time limit | An agent that hangs |
| The protocol version is one we support | A v1 agent, or a newer draft |
| The advertised capabilities are readable | A malformed `initialize` result |
| The process ends when its stdin closes, and it leaves no child | A leaked agent |

The third row is worth the command on its own: "the agent MUST NOT write
non-ACP content to stdout" is a protocol MUST, and an agent that breaks
it fails in a way that looks like a parsing bug in the CLIENT.

**Rendering.** The human report goes to stderr. When stderr is a
terminal, it goes through this repository's terminal layer
(`TerminalOutput.swift`, the one file that imports Noora). When stderr
is not a terminal, it goes through the Extras plain-text renderer.
`--json` writes the report to stdout. Exit 0, 1 or 5.

Every check carries a timeout. Name it in seconds. `doctor` must never
hang.

**The Extras dependency is ready.** The `Doctorable` module is on
`FoundationModelsExtras` `main` at `55d6b04`: `HealthStatus`,
`HealthCheck` (`name`, `status`, `message`, `fix`, `category`),
`Doctorable` (`doctorName`, `doctorCategory`, `isApplicable`,
`runHealthChecks()`), `DoctorReport` (`checks`, `worstStatus`,
`exitCode`) and `DoctorRunner`. A `main` branch dependency stays pinned
by revision until `swift package update` runs, so run it first.

**Two rules the module keeps, and this card must keep too.** A check
NEVER throws: a component that cannot run reports its own failure as a
`HealthCheck` with the `error` status, so one broken check cannot stop
the others. Every `warning` and every `error` carries a `fix` string.
