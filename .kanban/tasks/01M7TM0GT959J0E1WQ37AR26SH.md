## Problem

CI run 44584505762 (e7997a2): the integration test `aConnectionModelRunsOneTurnAgainstARealAgent` (`IntegrationTests/Tests/.../LiveAgentTurnTests.swift:37`) fails with `ConnectionError.closed` after 22 s. The real agent process stopped:

```
warning FoundationModelsACPAgent.Configuration: config.section=profile.flash ... The configuration has a key that is no longer used. The loader ignored the key.
warning FoundationModelsACPAgent.Configuration: config.section=profile.standard ... The configuration has a key that is no longer used. The loader ignored the key.
Fatal error: Error raised at top level: profile "large" did not resolve: ResolutionFailure: profile "large" cannot co-fit a budget of 26800603136 bytes.
```

Cause: `IntegrationTests/LiveAgentServer/Sources/live-agent-server/LiveAgentServer.swift` `userConfigYAML` writes the OLD format `profile: {standard: [...], flash: [...]}`. FoundationModelsACPAgent (D203: 20c96fc, bdf13fe, d5693f2, a357f54) replaced it with profile files, so the agent ignores both keys and uses its default by fit, `large`, which does not fit the CI runner (26.8 GB).

## The new format (FoundationModelsACPAgent README, "Profile files")

- A profile file is `<layer>/profiles/<name>.yaml`: Router's `ProfileDefinition` in YAML. Keys: `description`, `standard`, `flash`, `embedding`, `decision`, `context`, `decisionContext`, `kvBits`.
- `config.yaml` names the profile with `profile: <name>`.
- A key that the file leaves out takes its value from the SHIPPED profile `large` (not from the selected profile). Thus the test profile must name each slot with a small model, or the agent loads the large model of that slot.
