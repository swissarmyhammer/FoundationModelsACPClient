## What

Four files give a false reason for the logging bootstrap in `acp-client`. They say that the default handler of swift-log writes to standard output. That is not true. `.build/checkouts/swift-log/Sources/Logging/LoggingSystem.swift` sets the default factory to `StreamLogHandler.standardError(label: label)`. The error came from rule 6 of the OpenTelemetry design of 2026-09-28; its author (session swissarmyhammer-05) corrected it on 2026-09-28.

The code is still correct. The bootstrap is still necessary, but for a different reason: `cli-plan.md` §8 gives standard error to the terminal layer (`TerminalOutput`), and unrequested swift-log lines from the default handler would mix with that output. Standard output must still hold the answer text alone. Change only the text that gives the reason. Do not change behaviour.
